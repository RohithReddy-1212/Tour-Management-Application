 TourHub - Tour Management System

TourHub is a simple and interactive web-based application designed to manage and track travel tours.  
It allows users to browse and book tours, and **admins** to manage tour listings and view user bookings.
Features-
User
- Register and login securely.
- View all available tours.
- Book a tour using a clean booking form.
- Input validation for valid and future travel dates.
Admin
- Login with admin credentials.
- View all user bookings in a responsive table.
- Add new tours (instantly visible to users).
